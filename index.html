Glisse un fichier .json ici, ou
Format du fichier JSON 
{
  "id": "10", "index": "10",             // texte de l'indice (ex. "3bis")
  "color": "#DC9600", "textColor": "#000", // couleur de la ligne à l'écran
  "route": [                              // arrêts dans l'ordre du sens 1
    { "id":"a", "name":"Boulogne – Pont de Saint-Cloud",
      "lines":["Boulogne","Pont de Saint-Cloud"],   // version sur 2 lignes (optionnel)
      "tag":"UNESCO",                                // petit encart (optionnel)
      "corr":{ "metro":["9"], "rer":["C"], "train":["L"], "tram":["T2"], "ter":true,
               "short":{"line":"10","label":"Gare d'Austerlitz","dir":1} } },
    { "fork":{ "taken":"lower",                      // branche empruntée dans le sens 1
               "upper":[ {…arrêts…} ], "lower":[ {…arrêts…} ] } },
    { "river":"La Seine" },                          // trait bleu (optionnel)
    { "id":"z", "name":"Gare d'Austerlitz" }
  ]
}

Un arrêt peut aussi être une simple chaîne ("Odéon"). Le sens 2 est déduit automatiquement (liste inversée, branche opposée). Couleurs des correspondances : palette métro / RER intégrée.
